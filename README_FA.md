# سایت تولد ماهوش 💙🦋

این نسخه برای انتشار استاتیک در GitHub Pages آماده شده است. فایل اصلی `index.html` باید کنار پوشه‌های `assets/` و `songs/` در ریشه‌ی شاخه‌ی `main` قرار بگیرد.

## انتشار روی GitHub Pages

1. فایل ZIP نهایی را دانلود و استخراج کن.
2. **محتویات** پوشه‌ی استخراج‌شده را در ریشه‌ی مخزن و شاخه‌ی `main` آپلود کن؛ خود ZIP را به‌تنهایی در مخزن نگذار.
3. از `Settings → Pages`، گزینه‌ی `Deploy from a branch`، شاخه‌ی `main` و مسیر `/(root)` را انتخاب کن.
4. پس از انتشار، سایت را در گوشی و دسکتاپ باز کن. ارسال واقعی فرم Formspree باید با اینترنت آزمایش شود.

## تغییرات این نسخه

- چهار PNG تازه‌ای که در این گفت‌وگو دادی (`diary-open-book-transparent.png`، `birthday-cake-transparent.png`، `secret-envelope-transparent.png` و `diary-cover-stack-transparent.png`) بدون تغییر پیکسل و بایت‌به‌بایت استفاده شده‌اند.
- برای پس‌زمینه‌ها، تصویر در ویندوز با `cover` متناسب پر می‌شود و ممکن است از کناره‌ها کمی برش بخورد؛ تصویر کشیده نمی‌شود. در موبایل، تصویر واضح با `contain` کامل می‌ماند و لایه‌ی محوِ همان تصویر فضای خالی اطراف را پر می‌کند.
- تصویر ترکیبیِ مورد تأیید دفتر (`diary-open-book-with-memories.png`) دقیقاً ظاهر کتاب و شش پولاروید را مانند رندر تأییدشده حفظ می‌کند؛ تصویر اصلی کتاب و شش عکس جداگانه نیز کنار آن دست‌نخورده باقی مانده‌اند. شش ناحیه‌ی چندضلعیِ هم‌راستا با هر پولاروید قابل کلیک‌اند؛ با لمس هر عکس فقط همان عکس و متن همان خاطره در پنجره‌ی کاغذی باز می‌شود. بستن پنجره، فوکوس را به همان عکس برمی‌گرداند. در موبایل، کتاب با نسبت تصویر ثابت پیمایش افقی می‌شود تا عکس‌ها ریز نشوند.
- متن خاطره‌ها روی تصویر چاپ نشده است؛ متن‌ها HTML واقعی‌اند و اندازه‌ی صفحه/اسکرول را رعایت می‌کنند.
- صفحه‌ی چیستان از ۲۶۲ چیستان محلی با گزینه‌های چهارگانه استفاده می‌کند؛ قفل عاشقانه ۲۰ سؤال چهارگزینه‌ای دارد. بازشدن پاکت، کاغذی را بیرون می‌آورد و سپس به نامه می‌رود.
- کیک اصلی دست‌نخورده است؛ **هیچ بدنه‌ی شمعی به تصویر اضافه نشده**. فقط شعله‌های متحرک CSS در مختصات فتیله‌های موجود قرار می‌گیرند و هنگام تعامل خاموش می‌شوند. توجه: در تصویر کیک ارسالی ۲۰ بدنه‌ی شمع قابل‌مشاهده است؛ بنابراین ۲۰ شعله روی همان فتیله‌ها قرار گرفته‌اند. برای دقیقاً ۱۹ شمع باید تصویر کیکِ دارای ۱۹ شمع تهیه شود یا یک شمع از تصویر اجازه‌ی ویرایش بگیرد.
- انیمیشن نرم تغییر صفحات، پشتیبانی از کاهش انیمیشن، ۱۹ ستاره، پناهگاه روزهای سخت، بخش پرونده‌ها، رؤیاها، تنظیمات و منوها حفظ شده‌اند.
- هر ۱۴ پس‌زمینه‌ی قبلی و هفت فایل صوتی محلی نسبت به نسخه‌ی پایه بدون تغییر باقی مانده‌اند. پخش خودکار اجباری و سرویس دانلود موسیقی اضافه نشده است.
- آدرس فرم Formspree و مجموعه‌ی URLهای خارجی همان قبلی مانده‌اند: `https://formspree.io/f/xbgdnvyj`.

## پوشه‌ها

- `assets/`: پس‌زمینه‌ها، شش عکس خاطره، چهار تصویر PNG جدید، آیکون پروانه، تصاویر مکمل و `riddles.js`.
- `songs/`: هفت فایل صوتی محلی که پلیر استفاده می‌کند.
- `TEST_REPORT_FA.md`: خلاصه‌ی بررسی فنی و محدودیت‌های تست.
- `ASSET_MANIFEST.json`: مسیر نسبی، اندازه و SHA-256 دارایی‌ها.

## تست

بررسی نحوی JavaScript و CSS، شناسه‌های تکراری، مسیرهای دارایی و یکسان‌بودن فایل‌های اصلی انجام شده است. اجرای کامل کلیک‌ها، پخش واقعی آهنگ، ذخیره‌ی بعد از رفرش و ارسال فرم در مرورگر واقعی این محیط قابل‌تکمیل نبود؛ این موارد را پس از انتشار روی GitHub Pages بررسی کن.


## دفتر خاطرات

- برای دفتر، تصویر ترکیبیِ تأییدشده `assets/diary-open-book-with-memories.png` دقیقاً کتاب مایل و شش پولاروید را با پرسپکتیو تأییدشده نمایش می‌دهد. تصویر اصلی کتاب و شش عکس مستقل نیز به‌صورت جداگانه و بدون تغییر حفظ شده‌اند. شش ناحیه‌ی چندضلعی و قابل‌دسترس روی پولارویدها قرار دارد؛ کلیک روی هر عکس فقط عکس بزرگ و متن همان خاطره را باز می‌کند. بستن پنجره با ضربدر، دکمه‌ی برگشت یا Escape کار می‌کند و فوکوس به همان عکس برمی‌گردد. روی موبایل، کتاب با نسبت تصویر ثابت در یک ناحیه‌ی افقی پیمایش می‌شود تا عکس‌ها ریز یا کشیده نشوند.
